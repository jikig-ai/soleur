# Refresh-set for the ADR-135 pull-based signed config-refresh channel (#6780).
#
# One repo-relative path per line (blank lines and #-comments ignored). These are the
# host-executed *.sh scripts the CI producer (build-inngest-config-bundle.yml →
# inngest-config-bundle-pack.sh) packages, keyless-signs, and dual-publishes; the host timer
# pulls, verifies, and applies them IN-PLACE via infra-config-install.sh — no host replace.
#
# MEMBERSHIP RULES (binding):
#   • HARD-1 — the channel ENGINE is NEVER a member: inngest-config-refresh.sh (the verify+apply
#     script, Phase 4), the cosign binary, the baked verify anchor, the .timer/.service units, and
#     /var/lib/inngest-config/applied.version. Otherwise one signed bundle could replace the
#     verifier with an accept-all shim (signed-once → bypass-forever). These are NOT in DEST_SPEC.
#   • Every member MUST be an inngest-host dest in infra-config-install.sh DEST_SPEC (and its
#     FILE_MAP lockstep) — the channel reuses that root helper, it does not widen the dest set.
#
# #6780 decision D3 — membership is the FOUR dedicated-host carriers (five until inngest-luks-cutover.sh was retired
# with the cutover trio, #10112): the repo files that
# install to /usr/local/bin on soleur-inngest and whose every edit previously cost a full
# sole-scheduler force-replace (the inngest-redis-bootstrap.sh case is the exact shape this
# channel eliminates). The earlier 8-member seed listed web-host scripts — verified absent
# from cloud-init-inngest.yml; they belong to the webhook push channel, not this one — and
# is replaced here.
