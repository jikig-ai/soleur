# `SUITE_REGISTRATION<TAB><label>`) and argv is the command the job executes from the checkout root. A suite's non-zero
# exit propagates into the leg verdict; zero members would be a vacuous leg, so the job also reds on an empty manifest.
#

# oracle-SUT set minus the exclusion list below, so a NEW oracle-machinery registration cannot silently escape the leg.
