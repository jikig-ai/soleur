# WHAT THIS IS NOT. These are NOT 1089 defects. P1b asks whether an operand can be RELATIVE, or be
# rooted at `/` by an empty parent. It does not assert any of these is reachable with such a value
# today. The rows are the residue left AFTER the scanner resolved everything it could: mktemp in

# the scanner cannot see through — `never-bound` globals and positional parameters from a caller.

#   git -C         17      3   REMEDIATED INLINE in this change -- no git-C row appears below

# property for EVERY family reading that same variable, not just the one that motivated it. That
# is why the pre-remediation total of 1114 becomes 1089 and not 1097.
#
# `assert_fixture_dir` is a sound P1b guard, not merely a P1a one: its `case` rejects the empty
# string, `..` components, synthetic-fs paths and the filesystem root, accepts `/*`, and refuses

# guard that only rejected EMPTY would not be, and must not be added to this rule's recognised set.
