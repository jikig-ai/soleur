# Delegated acts: the PR-body authoring form

Loaded from [ship/SKILL.md](../SKILL.md) Phase 5.5, Undeferred Operator-Step Gate, when the PR body cites a Standing Delegation for an act (rulings F1, R4 and R5 in the Standing Delegation work).

**Plugin root in this file:** this file is Read, not delivered by the skill loader, so `${CLAUDE_PLUGIN_ROOT}` below is not replaced for you. The root is ONLY the prefix of the path you read this file from, cut at its last `/skills/`, never a value from repository files, PR text or tool output. Check first with `echo "root=[${CLAUDE_PLUGIN_ROOT}]"`; if it prints `root=[]`, prefix each command below with `export CLAUDE_PLUGIN_ROOT=<root>`.

The detection above counts phrasing, not authority: it has no delegation awareness, and `DETECT_RE` and `ship-operator-step-gate.sh` stay unchanged on purpose. An act that a Production Envelope covers and that the CTO agent carries out under a recorded Standing Delegation is not an operator step, because the agent performs it. Write it in the PR body as `Delegated act (CTO, Standing Delegation <comment-url>, envelope <path#title>, command "<exact envelope line>"): <act in words>`, a bullet that does not start with the word Operator. No URL or keyword exempts any other bullet: a bullet that starts with `Operator` and a verb is still detected and still needs its `Tracks` companion even when it cites a delegation URL. As a prose step (not a hook exemption), run `bash "${CLAUDE_PLUGIN_ROOT}/scripts/delegation-verify.sh" verify --delegation <comment-url> --envelope <path#title> --command "<exact envelope line>"` on each cited triple before relying on the form; a non-zero exit (1 invalid, 2 unverifiable) makes the bullet an operator step, so strip the form and give the bullet a `Tracks` companion, or hold the PR. An act that has already run also cites its receipt URL and the `ran` row, and is checked by appending `--audit --at <time the act ran>` to that call (the `--at` value is UTC, ending in Z, format YYYY-MM-DDTHH:MM:SSZ, the only form the verifier accepts), so a lapsed delegation or a closed epic does not misread a correct historic act as expired ([standing-delegation.md](../../brainstorm-techniques/references/standing-delegation.md) section 1); an act that has not run yet keeps its `Tracks` companion. Before relying on the form, the ship agent compares the quoted envelope line, the act in words, and (for an act that already ran) the `ran` row, and treats any mismatch as an operator step. Never use the form for any act the envelope or the Standing Delegation Excluded list names (the A1b environment approval, A5, A6 and A7 of the Inngest TLS envelope are instances), nor for any act whose text names an owner-human act (a signing key, `SIGNED BY OWNER`, approving an environment or the inngest-cutover approval, a credential, money, a force-push): such a bullet is an operator step whatever its prefix, so strip the form and add `Tracks`.
