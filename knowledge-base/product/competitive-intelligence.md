# Competitive Intelligence Report

## Executive Summary

This is the first full-landscape scan (all six tiers) since the report's inception; prior scans covered Tier 0 and Tier 3 only. **Three material shifts dominate.** First, **Polsia's trajectory reversed hard**: against the prior scan's "ARR fell to $450K / possible churn event" read, Polsia raised **$30M at a $250M valuation (Sound Ventures lead, True Ventures participating, May 2026)** and newer third-party reports cite ~$10M ARR / 7,600 customers / 85% month-two retention — though figures across sources remain contradictory (a Feb 2026 Mixergy interview implied ~$689K run-rate). The autonomous-CaaS thesis Soleur competes against is now venture-validated at scale, not fading. Second, **the plugin-layer competitor `alirezarezvani/claude-skills` grew from 235 to 337 skills (5,200+ stars, 12+ AI tools, 30+ agents, 70+ commands)** — it is iterating faster than Soleur's headline counts and remains the closest structural match in the landscape. Third, **platform billing across Tier 0 shifted to metered/credit models simultaneously** (GitHub Copilot AI Credits June 1 with 10–50x agentic cost spikes and backlash; OpenAI Codex Pro promo expiry June 1; Notion Custom Agents to $10/1,000 credits, Business/Enterprise only) — a pricing-environment signal Soleur's monetization plan must read against.

A NanoCorp data-reconciliation flag emerged: the marketing site (now confirming parent **Phospho Inc.**, Wilmington DE) lists Google Search Ads as "**Coming Soon**," contradicting the 2026-06-08 business-validation.md / prior CI intake that described ads + Vercel + Stripe as already shipping. The self-reported "$740k ARR in 33 days" also conflicts with a newer "$193k ARR in 3 days" founder claim and a ~$264 user-revenue leaderboard. All NanoCorp metrics remain marketing/unverified and now mutually inconsistent — see Cascade Results for the operator reconciliation note. Soleur's durable differentiation across all tiers is unchanged: the **workflow lifecycle (brainstorm → plan → implement → review → compound) with named per-stage artifacts**, the **git-tracked knowledge base as canonical memory**, and **founder-in-the-loop** vs. the fully-autonomous CaaS pack.

### Tier 0 Key Takeaways

1. **The entire Tier 0 IDE/agent layer repriced to metered/credit billing in the same window** (Copilot AI Credits, Codex token-based + promo expiry, Cursor dollar-bucket, Windsurf quotas, Notion credits). The Copilot 10–50x backlash is the clearest signal: agentic compute cost is now visible and resented. Soleur's git-native, predictable-footprint model is a positioning contrast worth sharpening — but Soleur's own hosted-platform pricing will live in this same metered-cost reality.
2. **OpenAI Codex Sites moves OpenAI into landing-page/app deployment** — the exact NanoCorp/Lovable wedge. Tier 0 and Tier 3 are converging from the platform side.
3. **The engineering-workflow gap inside Cowork is still the last Anthropic-plugin gap.** Soleur's highest-leverage Tier 0 positioning remains "the engineering + multi-domain CaaS that Anthropic does not ship." Plan for Anthropic closing it, not against it.

### Tier 1 Key Takeaways

1. **The Claude Code plugin/skill channel Soleur depends on is now openly contested**, with `alirezarezvani/claude-skills` larger on every count count Soleur historically led with. Soleur's win condition at this tier is workflow depth and product integration, not skill quantity.
2. **Cross-tool portability is the emerging table-stakes feature.** Both alirezarezvani (12+ tools) and Tier 0 platforms reward multi-environment reach. Soleur's single-environment distribution is the standout vulnerability at this tier.
3. **[2026-07-04] Not every Tier-1 peer is a competitor — some are methodology to mine.** `MerlijnW70/sota-scan` is a non-competing single skill whose benchmarking mechanics are sharper than Soleur's own audit skills on four counts (two-axis gap/impl confidence, persisted rubric + progress diff, clustering-for-fairness, comparator type-tags). The peer-plugin-audit sub-mode's value here was *mechanic extraction into existing Soleur skills*, not a competitive-threat assessment — a reminder that the audit output can be "adopt these patterns," not only "add/beat this competitor." Adaptation work tracked in the issues linked from the Tier-1 row.
4. **[2026-09-18] The most valuable thing a Tier-1 peer can hand us is a mechanic for a rule we already wrote but never implemented.** `mattpocock/skills` is a different-ICP engineering library with no competitive overlap, yet at audit its `wizard` skill was the missing implementation of **two standing Soleur hard rules** (`hr-multi-step-post-merge-bootstrap-script`, `hr-ship-message-no-operator-checklist`), and its `diagnosing-bugs` discipline was absent from `reproduce-bug` on all six mechanics checked. Both gaps have since closed: `operator-bootstrap` shipped under `#8287`, and `reproduce-bug` now carries 6 of 6 of those mechanics (`#8288`). The audit's weight sits on **improving existing Soleur skills**, not on adding theirs — see the [full audit](competitive-intelligence/audits/mattpocock-skills.md).
