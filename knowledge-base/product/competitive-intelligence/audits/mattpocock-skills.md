Internal context only: not for citation in public or marketing content, which does not quote competitor metrics.

**What it is.** Not a workflow — a ~570-line **design language** for agentic software factories, written as course material for the author's "Software Factory Part Two". Two halves: a **glossary** (Task / Trigger / Run / Runner, plus five service *slots* — ticket tracker, ticket source, git host, orchestrator, observability platform — each with an `_Avoid_:` synonym list), and a **design method**: *Start slow* (every trigger is an accelerator; the three brakes are automated checks, automated review, human review; throttle new triggers one at a time), *Fill every slot* (a three-design services table: all-GitHub / Linear / own tracker), *Question every task* (five questions per task, one dedupe question per ticket source). Concurrency/dedupe is structural in every `schedule`-generated workflow (`concurrency: group: schedule-<NAME>`, idempotency prechecks), not just advised.
