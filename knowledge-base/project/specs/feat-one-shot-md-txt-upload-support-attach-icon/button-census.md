# Button primitive census (Phase 6, task 6.3)

Generated by an AST scan (TypeScript compiler API, multi-line aware) of every `<Button ...>` under `apps/web-platform/components` and `apps/web-platform/app`, cross-checked against a real Tailwind v4 compile of `app/globals.css` to learn which caller utilities used to lose to the primitive's base box on emit order.

- Button call sites scanned: 276; sites with a `className`: 229; sites listed below (className passes padding / fixed size / radius / typography / display / gap classes): 188.
- Disposition **restored to pre-ADR-255 intent**: 115 sites. Before this change the primitive emitted `inline-flex gap-2 rounded-lg px-6 py-3 text-sm font-medium` as ordinary utilities in the same cascade layer as the caller's classes, so a same-property caller class either lost on emit order (the census marks which) or, for icon-only buttons, was inflated by the unconditional `px-6 py-3`. Pre-ADR-255 these were native `<button>`s carrying only the caller's classes (`git show fff36b6172^:<path>`), so the caller's class now winning, and icon-only buttons no longer being padded, is the original rendering.
- Disposition **unchanged**: 73 sites. Their caller classes do not touch a property the base box sets (e.g. `w-full`, `min-h-*` on a text button), or already won on emit order (variant-prefixed classes such as `md:px-3`), or the base box is the intended geometry.
- Kind column: `icon-only` = no text child (no `soleur-btn-pad`); `text` = text child (keeps `soleur-btn-pad` unless the caller overrides padding); `dynamic-children` = children come from an expression the scan cannot resolve (treated as text-bearing for the padding decision, i.e. `soleur-btn-pad` is emitted; the runtime `hasTextChild` decides).
- Categories: padding override (`p*`), display override (`flex`/`hidden`/`block`/...; a caller `flex` now deterministically beats the base `inline-flex`), rounded override, typography override (`text-xs`, `font-*`), gap override, fixed-size (`h-*`/`w-*`/`min-*`/`max-*`; includes `w-full`).
- Category counts (a site can be in several): fixed-size 72, display override 19, gap override 10, padding override 92, typography override 96, rounded override 127.

## Not covered by this change

Variant-vs-caller conflicts are unchanged: the variant classes (`bg-*`, `text-*`, `border`) stay ordinary utilities, and the gold variant's inline `style` background beats any caller `bg-*` (the chat composer send button shows the gold gradient, not the pre-ADR-255 flat amber). A site whose caller passes a `bg-*` therefore still races its variant exactly as before.
