# Tasks: registry-host at-rest posture emitter (#8386)

Derived from the plan AFTER plan review and deepen. Phase order is load-bearing: the
contract-changing edits (emitter shape) precede their consumer (the probe), and every RED task
precedes its GREEN pair.

**(1)** the heartbeat runs as root under `doppler run --config prd`, where every secret in the config

seams at RENDER time instead. **(2)** delivery costs a full replace of the fleet's sole container-pull
path, behind a workflow that is currently dead — so the suites are the only rehearsal there will be.
