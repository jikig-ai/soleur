## Plugin proxy policy

The two that carry neither today (`plugins/soleur/scripts/audit-flag-flip.sh`, `plugins/soleur/skills/provision-cloudflare/scripts/provision-cloudflare.sh`) gain `--disable` only if Rule D stays green without `--noproxy`; if Rule D demands `--noproxy '*'` once the call is credentialed through `--config -`, add it and state the behaviour change (a user's `HTTPS_PROXY` is ignored for that call) in the PR body and the ADR-202 addendum.
