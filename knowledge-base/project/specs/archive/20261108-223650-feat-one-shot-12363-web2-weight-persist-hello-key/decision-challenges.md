DEVIATES from the brief's wording (random_password) to meet its stated requirement (64 hex = 32 random bytes, masked). Names random_bytes.proxy_hello_hmac and doppler_secret.proxy_hello_hmac_key, both count = var.host_proxy_tls_enabled ? 1 : 0, project soleur, config prd only (PROXY_TLS_KEY/CERT exist only in prd), visibility masked, no keepers, no lifecycle block; the parity pin for the pair is a separate test, not a widening of the proxy-TLS quartet test; the redactor gets a fixture for the count-indexed address random_bytes.proxy_hello_hmac[0]. Rotation: no auto-rotation, and no replace or taint of the generator until the next PR accepts a previous key - each host reads the secret at container start, so a rotation leaves web-1 and web-2 on different keys during the rolling redeploy and a fail-closed hello would break the cross-host relay. |
