Method (a measurement method only; it bypasses nothing in a ship path):
- Each reading is a fresh `git clone` of the worktree at the PR commit `3010ff00ca` into its own directory, so it has its own
  git-common-dir (its own advisory lock, which is the only way the pool engages) and an empty per-worktree derive cache (cold).
- `origin/main` in the clone is set to the PR commit, so the PR's own runner edit is part of the base and the gate is not degraded to full.
- The replay is the pick of the 2026-11-04 amendment: the web-platform median pick `7af192071d` (8 files); its added files are removed and
  its modified files restored to the parent's content, then committed. Selection: 160 of 733 (always-on 116, edge 44), as in the baseline.
- Command: `env -u CI SOLEUR_PJ_FIFO=<0|1> SOLEUR_TEST_JOBS=4 TEST_TIMING_LOG=<file> bash scripts/test-all.sh --affected`, output stamped per line.
- Order in one session: r1 backfill, r2 `SOLEUR_PJ_FIFO=1` control, r3 backfill. No synthetic CPU burners; the machine carried its ordinary
  sibling-session load (loadavg is recorded at each start and end).
- Per-suite walls are the `*.timing.tsv` files (`suite<TAB>wall_ms<TAB>tmp_delta=...`, skipped rows included). The raw 18k-line
  stamped logs are not committed.
