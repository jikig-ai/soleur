| D3: how to take the one cold/warm `sel_s` measurement ("via workflow_dispatch") | technical | Ruled by CTO agent, 2026-10-15: document only, take the measurement in the PR C replay, and build no dispatch-only measurement workflow - verified that a `workflow_dispatch` run of `ci.yml` cannot reach the selector (the job is skipped off pull_request and the driver returns `reason=not_pr` at `GUARD:G2-NOT-PR` before any selector call) and that the pinned 90 s stage-2 budget would censor a cold pass anyway; my earlier ruling allowed "a workflow_dispatch run or the PR C replay", so the replay choice is inside it; the ADR amendment records the accurate procedure (fresh hosted runner, `time bash scripts/test-all.sh --print-selection --paths=README.md` twice, cold then warm, budget raised above the cold pass); Dissent: none against the plan's direction, but the Plan Review Log bullet that surfaces D3 as an open User-Challenge must be restated as ruled (the Session Summary likewise), since nothing about D3 is left for the operator |
| D4: notice reason token for the off-switch case | technical | Ruled by CTO agent, 2026-10-15: `switch_off`, placed after the stage-1 allowlist so only a doc-only diff reports it and stage-1 reasons are untouched - the same token already exists in `REASONS` of `scripts/ci-push-dedupe.test.sh` and `scripts/ci-draft-light.test.sh`, so one grep finds every dark lever and no new vocabulary is introduced |
| D5: job predicate `!= ''` versus `== 'on'` | technical | Ruled by CTO agent, 2026-10-15: `!= ''` - it matches the Q1 wording "unset or empty", keeps the `switch=invalid` telemetry for a typo such as `ON`, and leaves the exact case-sensitive compare to the driver's bash because Actions string comparison ignores case, so the driver gate is the second independent layer and `== 'on'` would silently accept `ON` |

| D7: yield of the change | technical | Ruled by CTO agent, 2026-10-15: proceed, no operator item - the measured saving is about 1.07 billed min per PR run (about 133 job-min/day at the ADR's 124 runs/day, about 1.1% of the 99.8 baseline) for the job gate and about 9 to 11 job-min/day for the driver gate alone, small but it removes a cost that buys no evidence; the honest trade is that the stage-2 evidence stream stops while dark and the PR C replay (escape rate under 2%) becomes the blocking pre-activation check, which the ADR amendment must state |
