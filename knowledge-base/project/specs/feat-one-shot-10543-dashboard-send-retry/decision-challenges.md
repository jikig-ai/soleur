| D4 — which gates re-run on replay | technical | Ruled by CTO agent, 2026-10-26: all of them (grant, tier switch, template gate, approve_every_time typed-confirm + hash echo); the existing-row lookup sits after them and before `writeActionSend`. Flip evidence: a double GitHub artifact on a replayed row older than 24h; then add an age gate and require a fresh approval. |
