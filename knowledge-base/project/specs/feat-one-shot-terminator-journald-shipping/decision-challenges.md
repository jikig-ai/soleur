# Decision Challenges - feat-one-shot-terminator-journald-shipping

The owner's brief reserved every technical fork to `soleur:engineering:cto`. One batched consult was run at plan time (2026-10-25, the CTO was told
not to ask the operator anything) with measured evidence: the stunnel 5.72 line shapes captured locally in a container, the Better Stack
`tls-health` series, the 2026-10-24 per-host row counts, the `inngest-userdata-budget.sh` output and the repository flow for the bootstrap image.
Every technical row below is ruled; none is pending. `soleur:ship` renders this table into the PR body.

Dissent noted: the filter couples the config to stunnel's wording, mitigated by a pinned fixture of the measured lines and by failing open |
