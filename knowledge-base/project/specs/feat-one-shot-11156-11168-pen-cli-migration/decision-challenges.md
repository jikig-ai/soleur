| Panel fork 1: respawn with a `hash` baseline whose fresh disk capture differs (or whose file is now missing): adopt silently, adopt with a note, or arm the refusal | technical | Ruled by CTO agent, 2026-10-26: (c) arm the refusal. Implementation: `decideStale` drops the `missing` refusal and the `arm` on it; `runGuardedSave` returns `recreated: true`; the adapter writes one stderr line (`[reason=recreated] <file> baseline=<hash8>`) and prefixes the `save` and edit results with `NOTE: <file> had been removed from disk (a branch switch, a move or a delete); this save recreated it from the session's copy - tell the user and check that the file belongs at that path`; the `missing` branch of `refusalMessage` becomes the respawn `file-missing` wording; the logRefusal code list and the plan's observability row for `reason=missing` change to `reason=recreated`.
