## 1. User-Challenge candidate: `rehearsal.tf` is not edited

- Operator wording: "Edit the `inngest-provision-rehearsal` root (apps/web-platform/infra/inngest-provision-rehearsal/rehearsal.tf and apps/web-platform/infra/inngest-provision-rehearsal.test.sh)".
- Ruled (R1): the goal (a rehearsal proving the recovery, landing before #10112) is met by a sibling suite; the root's `.tf` files stay untouched, and `inngest-provision-rehearsal.test.sh` is edited (one additive pointer assertion).
- What the default (the operator's literal wording) would cost: a `random_password.rehearsal_*` resource in the real-R2 root breaks two pinned contracts of that suite and enters the encryption-posture ledger scope; a comment-only edit buys no property and adds a conflict with #10112.
- Decide: keep the ruling (default for the plan), or require a literal `rehearsal.tf` edit (the plan would then add a comment-only pointer, nothing structural).
