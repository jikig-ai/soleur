| F2 - the quorum constant: name, home and whether it is tunable | technical | Ruled by CTO agent, 2026-10-20: `export const PROMOTION_QUORUM = 5` in `cron-compound-promote.ts`, a code constant and NOT operator-tunable, interpolated into the phase-1 prompt, the check and the `Threshold-Hit: N/${PROMOTION_QUORUM}` trailer - the quorum guards what may be promoted into always-loaded rules (ADR-092) so a config-only change must not be able to weaken it, and there is exactly one consumer file so a shared module is indirection.
