# Decision challenges: S7c plan (tracker #9217)

Recorded while planning S7c (derivation recall). The pipeline runs unattended and keeps the brief's direction on every point below; each can be reversed in a follow-up. Class is per the decision-principles doc (mechanical items were applied and are not listed).

1. **The any-producer arm (R3) is kept, last in the commit order, cuttable at ship time, and shipped only with every new pair reach-classified.** The brief names "a producer other than printf/echo/cat". Four independent signals argued for cutting it from this PR: the scoped advisor consult, the DHH seat, the simplicity seat and the devex (CTO) seat. They read the first J0 draft, in which the arm was 63 of 113 new pairs with about a third prose noise. The plan since added quote parity and a case-pattern exclusion to the arm and to the measurement: it now reads 47 pairs (U2 is 90 pairs in 66 test files, 14 suites reached by no other arm), about 7 of them noise. What still argues for a cut: a second site source plus quote parity that nothing else uses, an under-derivation for a bar inside `"$( ... )"`, 14 more suites in the reach probe, and the guard moving toward the 15 s preflight cap. What argues for keeping it: a producer-agnostic scan is what the property says, and J0 shows real `logger`, `jq`, `tar`, `psql` and `timeout` pairs only this arm sees. Default taken: keep, ship last, and cut it if its reach tranche cannot be completed or the quiet-host guard time passes 12 s. Class: User-Challenge (four signals say drop operator-named scope); the brief's direction is the default.
2. **The new bar scan is added as a second site source and unioned with the old `printf|echo|cat` scan, not substituted for it.** Substituting would be simpler to read but would move the meaning of the 66 existing rows and the 120-triple pin. Class: taste.
3. **Quote parity on the text before a bar, not a shell lexer.** Repo learning #8667 says a guard over a structured language should lex it. Not adopted: the guard is a line scanner by construction (S7b), a lexer for strings, comments, heredocs and `$( )` depth in awk is its own slice, and the under-derivation is bounded and listed under NOT fixed. Class: taste.
4. **Reach classification runs before any awk arm is written (Phase 0 precedes Phase 2), but an arm is not dropped because its new pairs are all TEXT.** The advisor suggested letting the reach table choose the arms. An arm also buys the recall property for FUTURE pipes, at the price of rows; the per-arm EXEC count is recorded so the ship-time cut of the last arm is argued from data. Class: taste.
5. **No ADR for the guard architecture.** The S7b ledger deferred it to this slice. Nothing in the diff changes a substrate or a trust boundary, and the semantics are still open (R3 may be cut, Items D to I remain); the guard header and `evidence.md` carry the record. Class: taste.
6. **The brief's "cloud-init-inngest-bootstrap.test.sh is red at base" is not supported by CI.** #9956 closed on 2026-10-11 (PR #10053) and `Infra Validation` is green on main in every run since `47c38a19da` where the job ran; the suite is red only in the local isolated sandbox for an environmental reason (no tags). The file stays untouched as instructed, its two pairs are reclassified in a real clone, and the two `blocked-#9956` rows are reworded to a reason that is true. Class: User-Challenge (a stated premise looks stale); the instruction to leave the file alone is the default.
7. **Library pipes use the "sourced by a file that has pipefail" reading (R4b: 10 pairs), not forced-on (18) or "the owning test has pipefail" (18).** A subprocess does not inherit the option (measured: a child shell run under a parent with pipefail reports the consumer's status). Class: mechanical-leaning, listed for the record.
8. **R6 is an extension list only (`.tf .tftpl .template .service .tmpl`); extensionless producers are cut.** Measured 0 pairs; 4 extensionless shebang files hold no text pipe. Class: taste.
9. **Two arms were added that the brief did not list: R7 (the stub-name `";` defect, 7 pairs) and R8 (the annotation strip bounded at its string, 1 triple).** R7 was found by J0; R8 is the late finding about a pipe sharing a line with an annotation echo, re-measured wider than a first grep suggested (29 lines). Class: taste (small, same class as the brief's list).
10. **The preflight probe cap.** The declared discoverability command is the guard itself (8.2 s at load 5.5 at plan time; cap 15 s). If the quiet-host figure exceeds 12 s after the arms land, the command is replaced by a script that prints the last-run summary line. Class: taste.
11. **Lane.** The branch has no `spec.md`, so the plan classifies the lane itself (`single-domain`), as S7b did, rather than defaulting to `cross-domain`. Class: taste.

Each is one regex or one list entry with its own fixture, so they stay; an arm is not cut for having only TEXT pairs because the property is about future pipes (decision 4). 13. **A `--print-pins` and `--explain <suite> <verb>` mode for the guard (devex seat) are not added.** The pin failure messages already print the recomputed value, and the `unlisted pair` message now names the producer file; a command-line surface on a hook suite is new machinery. Class: taste.

The measurement (`j0-derive.py` R1) is the join, and the awk now matches it. Class: mechanical (applied from the correctness seat).

## Added at Phase 0 (J0 measurement; evidence in `evidence.md`)

19. **`- |` (a YAML list-item block scalar) is read as a pipe by R1 plus R3, and it adds four noise pairs.** R1 joins a physical line that ends in a single bar with the next line, and the block-scalar exclusion only knows `key: |`; R3 then reads the bar as a pipe from `-`. The four pairs are `grep-q-pipe-guard.test.sh set`, `test-argv-bearer-sweep.sh set`, `ci-deploy.test.sh systemctl` and `inngest.test.sh systemctl` (cloud-init `- | set -a`, `- | systemctl daemon-reload`; 12 sites in three cloud-init files). Measured with the exclusion widened to `(:|(^|[ \t])-)[ \t]*[|>][-+]?[ \t]*$`: U2 reads 86 pairs, 136 triples, 65 test files (R3 alone is unchanged at 47). Default taken: widen the exclusion in `j0-derive.py` and write the same widening into the awk, so the four pairs never need a row; until then the four are `exempt not-a-command` rows in `reach-table.tsv`. The plan's "about 7 still noise" for R3 is 11 noise pairs of the 33 pairs only R3 reads (four from this defect). Class: mechanical (a measurement defect).
20. **Measured update to item 6: the `cloud-init-inngest-bootstrap.test.sh` pairs are EXEC and the suite is green at base.** Run in a real local clone with tags (`vinngest-v1.1.50` present), the suite passes 240/240 in 12 s, so `blocked-#9956 suite red at origin/main` is untrue on this host as well as in CI. Both pairs (`docker`, and `timeout` in front of it) are reached by a piped `login 10.0.1.30:5000 -u zu --password-stdin` (5 hits each) and the docker stub (def 2004) never reads stdin. The file stays unedited (the brief). The two rows need a truthful reason: the closed vocabulary has no word for "reached, never drains, fenced", so the default is `blocked-#N` with N a new tracking issue for the drain (a deferral per `wg-when-deferring-a-capability-create-a`), not a new vocabulary word. Class: User-Challenge (the stated premise is false; the instruction to leave the file alone is the default).
21. **Absence and fault stubs (`exit 127`, `exit 2`, `exit 255`, `exit 1` as the first statement) are `exempt deliberate-fault`, not edits.** Under pipefail the stub is the last stage and a non-zero exit makes its own status the rightmost non-zero one, whether or not the producer took SIGPIPE, so the verdict is decided by the stub and not by a write race; only a never-reading stub that exits 0 can flip a status to 141. Nine suites carry such stubs (guardrails perl, zot-disk-heartbeat-redaction jq, ship-incident-pir-gate-mutation awk, destructive-command-guard-hook perl, infra-config-activation-7220 python3, check-deploy-script-parity python3, test-argv-bearer-sweep python3, browser-snapshot-credential-guard jq, and the ci-deploy `tr` row already listed); they are excluded from the edit count and reported beside it. S7b edited one such stub (`workspaces-plaintext-hold-9348` jq, `exit 127`); that row stays. If Phase 3 prefers to edit them too the edit list grows from 7 suites (4 infra) to 15 (5 infra). One mixed case is an edit: `test-zot-log-channel-probe.sh` awk has an `exit 1` stub (deterministic) and an `echo not-a-summary; exit 0` stub (race-capable). Class: taste.
22. **Ten pairs are UNVERIFIED because the suite hit the 300 s cap (or is red for a host reason) and no matching piped call was seen.** Suites at the cap on a host at load 14 to 40: ci-deploy, check-web-host-escrow-config, destructive-command-guard-hook, workspaces-boot-unlock, test-git-data-birth-readiness-gate, test-argv-bearer-sweep, web-host-reboot, workspaces-luks-provision (killed at 305 s), git-data-cutover-access and test-sentry-alert-live-fidelity (real-clone re-run). `fixtures-validate-infra-templates.sh` is red for a host reason (no `cloud-init` binary here; CI has one). A partial run still proves reach when it logged a matching hit (those pairs are EXEC) but cannot prove a TEXT. A quiet-host re-run would settle them; the plan's "run once" rule was kept. Class: taste.
