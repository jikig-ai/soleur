Planning-phase decision record (2026-11-03). Technical forks were ruled by the CTO agent (the operator is never asked a
technical question); the plan-review panel (DHH, Kieran, code-simplicity, architecture-strategist, spec-flow) then
dissented on several, and the CTO re-ruled them (D-rows, which supersede the T-rows they name). The only operator-class
