# Learning: a source-hop regex was quadratic on one long token, and my own stale runs held the test queue

## Problem

PR #10671 (S4 affected-index PR1b, audit reach, Ref #10448 / Ref #9729) widened `scripts/ci-pr-affected-replay.py` so the audit reads a suite's depth-8 `source` closure plus a naming walk over the code files its selector row lists. Two classes of defect surfaced after the implementation looked green:

1. `SOURCE_HOP` (the regex that extracts `source <operand>` targets) was **quadratic**: a single `source $<identifier>...` token of 80k characters took 11 s, because the operand prefix could be re-tried from every start offset. Unit rows on realistic input all passed; only a hostile-width cost row found it.
2. Several correctness gaps that a green suite did not show: rows of one label sorted by their *first* pattern (ordinal ties), the closure of a walk level's files was read but never fed the *next* level's naming, a runner trigger as a row's first pattern was treated as a suite, and `.jsx` was missing from the code extensions.

Separately, the local affected-tests gate sat "queued, not hung" for over 40 minutes. The lock holder was **my own** stale `test-all.sh` processes from earlier in the session (three of them), not another worktree's run.

## Solution

- Add a `(?=/)` lookahead after the operand prefix so each start offset fails in O(1); pin it with a cost row (`row_hop_redos`) that runs one long token and bounds the time, plus a mutant that removes the lookahead.
- Sort a label's rows by the whole pattern list; read each walk level as "walk files by sorted path, then their source closures", and let BOTH feed the next level; refuse a runner trigger as a suite file; add `.jsx`.
- Re-implement the selector's edge grammar in the audit and differential-test it against the REAL bash `_diff_edge_hit`/`_diff_touches`, extracted from `scripts/test-all.sh` by content anchors (50-row table), instead of trusting a hand-written mirror.
- For the queue: `source plugins/soleur/scripts/lib/proc.sh; list_runs test-all.sh` shows `mine`/`foreign` per pid; `kill_mine test-all.sh` releases only this worktree's runs. Then re-run detached; if the gate still reports `AFFECTED_GATE_BUDGET_DEFERRED` (rc=6, queue wait ate the budget), CI is the authoritative gate and the replay suite alone (712 assertions, 298 mutants) is the local evidence.

## Key Insight

A variable-width regex fed attacker- or repo-controlled text needs a cost row on ONE long token, not only many short ones; "every positive and negative case passes" says nothing about time. And a detached background run that dies without writing its rc file looks identical to a run that is still waiting — check the process table (`list_runs`) for owner and liveness before concluding anything is blocked by someone else.

## Session Errors

1. **SOURCE_HOP quadratic (11 s at 80k chars)** — Recovery: `(?=/)` lookahead + cost row + mutant — Prevention: any new regex over repo text ships with a one-long-token cost row (done in this PR).
2. **Walk-closure never fed the next walk level / row-sort ties / runner-trigger-as-suite / `.jsx` missing** — Recovery: fixed in review rounds 1-2 with level-order and tie rows — Prevention: order-sensitive reads get a row that asserts the read ORDER, not only the set.
3. **Transient `No space left on device` failed two suites in the affected gate (rc=6)** — Recovery: both passed in isolation — Prevention: re-run the two suites in isolation before reading rc=6 as a regression.
4. **Scratchpad wiped by a restart (seat reports, pinned tree, rows file lost)** — Recovery: rebuilt `pin/`, `rows.txt`, `old-sut.py`; the receipt generator is deterministic and regenerated byte-identical — Prevention: keep receipt inputs reproducible from a pinned SHA via the committed generator; never store the only copy of a review panel report in scratch (copy conclusions into `decision-challenges.md`).
5. **Own stale `test-all.sh` runs held the advisory lock; gate "queued, not hung" for 40+ min** — Recovery: `list_runs`/`kill_mine test-all.sh` — Prevention: before starting a second detached gate in a worktree, `list_runs test-all.sh` and kill own leftovers; a detached run with no rc file after a restart is dead, not waiting.
6. **`pgrep -af` blocked by the hook and `kill_mine`/`list_runs` called without their required `<pattern>` argument** — Recovery: used the documented `list_runs <pattern>` / `kill_mine <pattern>` — Prevention: read the helper's usage line (it prints on a bare call) before the second attempt; the hook message already names the sanctioned helpers.
7. **Local affected gate `AFFECTED_GATE_BUDGET_DEFERRED` (rc=6)** — Recovery: recorded; CI is authoritative — Prevention: queue wait counts against the budget, so clear own queue entries first (item 5).
