# AEO Audit — soleur.ai — 2026-10-05

## Executive Summary

**Score: 76/100 (SAP headline) -- Grade B+.** Delta vs 2026-05-25: **+3** (73 C -> 76 B+). 8-component diagnostic: **81/100** (+2 from 79).

Structure improved most. Two of the prior cycle's recommendations shipped: `/getting-started/` now opens with a plain-language definition of Soleur plus three external citations (BSL 1.1 license, Claude Code docs, MCP spec). A new `/glossary/` defines 10 terms, each opening with a bolded one-sentence quotable definition and an external citation (Anthropic, LangChain, arXiv, Karpathy, Addy Osmani). The homepage "Soleur vs. Cursor and GitHub Copilot" comparison moved out of a collapsed FAQ into its own visible section.

Three things held the score back:

1. **Presence has not moved (14/25) for a third cycle.** The citation-monitoring tracker (`citation-monitoring.md`) was created on 2026-06-15, but every one of its 32 cells is still `TBD`. Roughly 16 weekly runs were missed. No third-party review or listing surface (Product Hunt, HN, G2) is referenced anywhere in owned content.
2. **Authority fixes from the last cycle were not applied.** The `/company-as-a-service/` pillar still says "The 100th session is dramatically more productive than the first" and "Soleur is a leading company-as-a-service platform". It also has a paragraph that opens "The numbers tell the story." and then gives no numbers.
3. **New entity-accuracy risk on `/vision/`.** Its feature cards describe unshipped capabilities in the present tense ("Plug in your own API keys (Anthropic, OpenAI, Gemini, Llama...)", "Claude for coding. GPT-4o for strategy."). Its own FAQ contradicts this: "The current implementation runs on Claude Code." AI engines that extract the cards will state that Soleur supports OpenAI, Gemini, and Llama today, which is false.

**Method note:** WebFetch was blocked in this environment by the `cron-containment` hook, so the audit ran on the Eleventy templates and markdown that generate soleur.ai, not on the rendered live site. Template variables (`stats.agents`, `stats.skills`, `stats.departments`) were not resolved to numbers. Off-site Presence (third-party mentions, live AI-engine answers) could not be checked, so the Presence score is carried forward from on-repo evidence only.

## Rewrite suggestions

| # | Page | Current | Suggested | Rationale |
|---|---|---|---|---|
| R1 | `/company-as-a-service/` | "Soleur's knowledge base has compounded across hundreds of merged pull requests. The 100th session is dramatically more productive than the first -- not because the agents improved, but because the institutional knowledge accumulated." | "Soleur's knowledge base has compounded across hundreds of merged pull requests. Each session starts from every decision, convention, and lesson recorded before it, so later work begins with context the first session had to build from scratch." | Removes an unmeasured superlative and keeps a factual, quotable mechanism. |
| R2 | `/company-as-a-service/` FAQ | Q: "What is the leading CaaS platform?" A: "Soleur is a leading company-as-a-service platform..." | Q: "Which platforms offer Company-as-a-Service?" A: "Soleur is a source-available Company-as-a-Service platform that deploys {{ stats.agents }} AI agents across {{ stats.departments }} departments over one shared knowledge base. Other platforms building on the model take different positions on how much autonomy the AI should have; see the comparisons below." | AI engines discount self-ranking. A neutral answer is more likely to be cited and matches the query people actually type. |
| R3 | `/company-as-a-service/` | "The numbers tell the story. The Claude Code plugin ecosystem is growing fast, but the overwhelming majority of plugins focus on engineering tasks." | "The Claude Code plugin ecosystem is growing fast, and most of it targets engineering: of the plugins listed in [named marketplace/registry, with count and date], [N] focus on code." (Or drop the "numbers" framing if no count is available.) | Turns a vague claim into a citable statistic, or removes the promise of numbers that never arrive. |
| R4 | `/vision/` hero | "Where Soleur is headed." | "Soleur's vision is a Company-as-a-Service platform that lets one founder run a billion-dollar company. Today Soleur runs on Claude Code with AI agents across 8 departments. The roadmap below extends it to multi-model orchestration, hardware, and beyond." | Gives the page a factual summary engines can quote, and separates the current state from the roadmap (also fixes F3). |
