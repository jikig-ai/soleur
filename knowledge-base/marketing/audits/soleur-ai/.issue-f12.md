## Defect

`plugins/soleur/docs/pages/agents.njk` says each agent "is trained" for its function (body, visible FAQ and JSON-LD). Soleur agents are not trained models; they are configured instructions on top of the user's model. Answer engines quote JSON-LD word for word, so the claim propagates. The same page says agents run "within Claude Code", which contradicts the supported-tool list (#11833).

- "is trained" → "Each agent is set up for one function…" in body, FAQ and JSON-LD
- Drop the Claude-Code-only wording; refer to "the AI tool you already use"
- Re-date `last_updated` (2026-06-01) only in the same PR, after the facts change (#11138)
